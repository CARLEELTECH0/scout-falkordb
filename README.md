# Scout: Autonomous Enterprise Knowledge & Security Investigator

> Autonomous graph intelligence engine built on FalkorDB for Graph Hacks 2026.

## Overview
Scout unifies three operational dimensions into a single graph database:
1. **Track 3 (Company Brain)**: Enterprise organizational fabric and asset access lineage.
2. **Track 2 (Agent Memory)**: Episodic session history and semantic concept mapping.
3. **Track 1 (Action Agent)**: Autonomous 4-hop multi-step security triage and asset containment.
